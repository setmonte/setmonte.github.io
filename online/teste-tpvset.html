👁 TPV-SET

Teste de Percepção Visual — adaptação do jogo SET

📚 Informações Técnicas

Instrumento: Teste de Percepção Visual (TPV-SET), adaptação do jogo SET para rastreio perceptivo
Base teórica: Integração de características e busca visual (Treisman); ciclo perceptivo (Neisser); controle inibitório (Barkley)
Estrutura: 3 rodadas, grade 3x3 de cartas, cronômetro de 10s por rodada
Tarefa: clicar nas cartas que formam conjuntos (SET) em linhas, colunas e diagonais
Resultado: média de acertos, falsos positivos, curva entre rodadas, perfil por direção
População: A partir de 6 anos — instrumento exploratório de rastreio
Normas: Provisórias (parâmetros de referência) — sem validação formal

👉 Como funciona

O que é um SET?

Um SET é um grupo de 3 cartas em que cada característica (cor, forma, número de símbolos e preenchimento), olhada uma de cada vez, é toda igual nas 3 OU toda diferente nas 3.

Atenção à regra: NÃO vale ter duas iguais e uma diferente em nenhuma característica. Se, por exemplo, duas cartas são vermelhas e uma é verde, aquele grupo não é um SET.

Neste teste, os SETs sempre estão em linha, coluna ou diagonal da grade 3x3.

Exemplos

✓ ISTO É um SET

✗ ISTO NÃO É um SET

O que fazer

• Observe a grade de 9 cartas.

• Clique nas 3 cartas que formam um SET (em qualquer direção).

• Marque todos os SETs que conseguir enxergar.

• Você tem 10 segundos por rodada, e são 3 rodadas.

Atenção: o relógio fica visível e corre rápido. Trabalhe com atenção, mas sem demorar.

Antes de valer, você fará uma rodada de treino (sem tempo e sem pontuação), em que o programa diz na hora se o grupo que você marcou é ou não um SET. Assim você pega a regra com calma.
