🧠 Vineland-3

Escala de Comportamentos Adaptativos — 3ª Edição

Formulário de Pais/Cuidadores dos Níveis de Domínio

📚 Informações Técnicas

Instrumento: Vineland-3 — Vineland Adaptive Behavior Scales, Third Edition
Autores: Sparrow, Cicchetti & Saulnier (2016)
Estrutura: 145 itens adaptativos + 35 itens de problemas de comportamento
Domínios: Comunicação (40), Atividades de Vida Diária (40), Socialização (40), Atividade Física (25)
Problemas de Comportamento: Seção A — Internalizante (13), Seção B — Externalizante (11), Seção C (11)
Pontuação: 2 = Usualmente, 1 = Às vezes, 0 = Nunca
Resultado: Pontuação Padrão (M=100, DP=15), Percentil, CCA
População: 0 a 90+ anos (tabelas normativas a partir de 3 anos)

📋 Dados Pessoais

📝 Instruções

Pontue cada item 2, 1 ou 0:
2 = Usualmente ou Frequentemente — a pessoa apresenta o comportamento sem ajuda ou lembretes
1 = Às vezes — a pessoa às vezes apresenta o comportamento sem ajuda ou lembretes
0 = Nunca — a pessoa nunca realiza o comportamento ou nunca o executa sem ajuda

Clique no domínio para expandir os itens. Marque a caixa "Est" (Estimativa) quando não tiver certeza da pontuação.

Dados anônimos e não-identificáveis podem ser utilizados para fins de pesquisa e normatização.
